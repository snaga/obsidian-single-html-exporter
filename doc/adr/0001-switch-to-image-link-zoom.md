# ADR-0001: Lightbox 方式から別タブ画像リンク方式への変更

## Status
Accepted

## Context
当初、エクスポートされた HTML 内で画像のオリジナルサイズを表示するために、CSS-only の Lightbox 方式を採用していました。これはチェックボックスハックを用いて、画像クリック時に `position: fixed` のオーバーレイを表示するものでした。

しかし、以下の問題が発生しました：
1.  **スタック文脈の干渉**: Obsidian が生成する親要素（`.app-container` など）に `transform`, `contain`, `filter` 等が設定されている場合、新しいスタック文脈が生成されます。これにより `position: fixed` の基準がビューポートではなく親要素になり、ページをスクロールした状態で画像をクリックすると、ズーム表示がページ最上部に固定されて見えなくなる不具合が発生しました。
2.  **実装の複雑化**: スタック文脈のリセットを試みましたが、Obsidian の複雑な CSS レイアウトを完全に制御することは困難であり、ブラウザ間の挙動の差も懸念されました。

## Decision
Lightbox 方式を廃止し、画像を `<a>` タグでラップして `target="_blank"` で開く「別タブ画像リンク方式」に変更します。

具体的には：
-   `HtmlPacker` から Lightbox 用の CSS と HTML 構造を削除。
-   画像を `<a href="DATA_URI" target="_blank" class="image-link">` でラップ。
-   設定項目名を `Enable image zoom (open in new tab)` に変更。

## Consequences
### Merits
-   **確実性**: ブラウザ標準のリンク機能を使うため、スクロール位置や CSS レイアウトに左右されず、100% 確実にオリジナルサイズが表示されます。
-   **機能性**: 別タブで開くことで、ブラウザ標準のズーム、右クリック保存、印刷機能がそのまま利用可能です。
-   **軽量化**: 複雑な Lightbox 用 CSS を排除でき、HTML ファイルがより軽量になります。

### Demerits
-   ページ遷移（タブ切り替え）が発生するため、Lightbox のようなシームレスな視覚効果は失われます。
