# 製品概要 (product.md)

## 🌟 製品の目的
Obsidian で執筆した Markdown ノートを、CSS スタイルと埋め込み画像（Data URI）を含んだ単一の HTML 形式でエクスポートするプラグイン「Obsidian Single HTML Exporter」を提供します。
「見た目そのまま」を 1 つの HTML ファイルで完結させ、フォルダ構造や外部リソースに依存せずに他者へ共有したり、アーカイブしたりすることを可能にします。

## 🎯 ターゲットユーザー
- Obsidian のデスクトップ版（PC）を使用しており、ノートをレイアウトを崩さずに知人や同僚に共有したいユーザー。
- ノートを単一ファイルとしてバックアップ・アーカイブしたいユーザー。
- 画像フォルダの管理を気にせず、ウェブブラウザで閲覧可能な形式で書き出れたいユーザー。
- MHTML 形式をサポートしていないデバイスや環境でも、標準的な HTML としてノートを閲覧したいユーザー。

## ✨ 主要機能 (Core Features)
- **WYSIWYG レンダリング**: Obsidian 標準のレンダラーを使用し、テーマ、数式（MathJax）、図解（Mermaid）を再現。
- **スタイル埋め込み**: 現在適用されているテーマおよびユーザー定義の CSS スニペットを HTML 内にインラインで統合。
- **画像・リソースの埋め込み (Single HTML)**: Vault 内のローカル画像だけでなく、インターネット上の外部画像 URL（HTTP/HTTPS）も自動ダウンロードし、**Base64 エンコードされた Data URI として HTML 内に直接埋め込み**。完全なオフライン閲覧を実現。
- **画像のオリジナルサイズ表示**: エクスポートされた HTML 内の画像をクリックすると、オリジナルサイズを同一画面上で表示可能（オプション、CSS-only Lightbox）。
- **ブラウザ自動起動**: エクスポート成功時に、保存されたファイルをデフォルトブラウザで即座に開く（オプション）。
- **タイトル表示**: エクスポートされた HTML の冒頭に、元のノート名をタイトルとして表示（オプション）。
- **YouTube 埋め込みの変換**: ノート内の YouTube 埋め込み（iframe 等）を自動的にサムネイル画像に変換して埋め込み。クリックするとブラウザで YouTube 動画が開くリンクを付与。

## 🚀 ビジネス目標 / ゴール
- Obsidian の強力な表現力を、Obsidian 外でも損なわずに利用できるポータビリティを実現する。
- 外部ツールを使わず、ブラウザ互換性の高い単一 HTML 形式で軽量なエクスポート体験を提供する。

## ⚠️ 制約事項 / スコープ外
- **モバイル対応**: 今回のフェーズではデスクトップ版（Windows/macOS/Linux）のみをターゲットとする。
- **ファイルサイズ**: 画像を Base64 形式で埋め込むため、元の画像ファイルサイズよりも HTML ファイルが約 33% 程度肥大化する可能性がある。
- **CSS の最適化**: 現在、ファイルサイズ削減のための PurgeCSS 適用は保留中。
- **インタラクティブ要素**: 動的なプラグイン（Dataview のクエリ結果など）は、レンダリング時に静的な HTML に変換された範囲のみサポート。
